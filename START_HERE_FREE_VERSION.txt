1. Open QUICK_START.md
2. Follow the setup steps
3. Run the server
4. Open the web application in your browser

═══════════════════════════════════════════════════════════════════════════════

WHAT THE PROJECT DOES

The system:

• Accepts resume text as input
• Extracts skills and experience
• Matches resumes with available jobs
• Ranks the top matching jobs
• Generates match explanations
• Asks a follow-up clarification question

RUNNING THE PROJECT

After setup, start the server using:

python -m uvicorn api.index:app --reload

Then open:

http://127.0.0.1:8000

API documentation:

http://127.0.0.1:8000/docs
